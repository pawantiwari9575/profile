# Pawan Tiwari Portfolio
 https://pawantiwari9575.github.io/profile/

## Folder Structure

```text
outputs/
  index.html
  css/
    style.css
  js/
    main.js
```

## Files

- `index.html`: Portfolio content and page sections.
- `css/style.css`: Layout, colors, glass cards, responsive design, and animations.
- `js/main.js`: WebGL background, motion, counters, scroll reveals, and navigation state.

## Preview

Run a local server from the project root:

```bash
python3 -m http.server 4173 --directory outputs
```

Then open:

```text
http://localhost:4173/
```
